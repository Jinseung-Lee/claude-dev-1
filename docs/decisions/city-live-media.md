# City live media

## Decisions

- 도시의 실시간 영상은 공식 채널이 임베드를 허용한 유튜브 라이브 영상만
  쓴다. 도시별로 사람이 직접 확인해 미리 등록해 둔 목록에서만 제공하고,
  임의의 도시를 자동으로 검색해 영상을 찾는 기능은 만들지 않는다.

## Boundaries

- Windy Webcams API, 런던 TfL·싱가포르 LTA·뉴욕 DOT·서울 TOPIS 같은
  도시별 공식 교통 카메라 API는 이 결정의 범위에서 제외한다.
- 이 결정은 실시간 "영상"에만 적용된다. 날씨(Open-Meteo)나 지도(Leaflet)
  등 이미 결정된 다른 데이터 공급원에는 영향을 주지 않는다.

## Why

Windy Webcams API는 API 키·회원가입이 필수이고 무료 요금제의 이미지
URL도 10분마다 만료된다. Windy의 무인증 embed 위젯은 약관상 상업적
애플리케이션에서의 사용을 금지하고 미디어 용도로만 허용해 라이선스
위험이 있다. 도시별 공식 카메라 API는 각각 별도 신청·계약이 필요하고
특정 도시에만 적용되는데, 이 앱은 사용자가 어떤 도시든 자유롭게 여행에
등록하는 구조라 일부 도시만 혜택받는 방식이 앱의 핵심 흐름과 맞지
않는다.

유튜브 표준 임베드는 게시자가 허용한 경우 키 없이 쓸 수 있어, 지금까지
지켜온 무인증 기조와 맞는 유일한 실현 가능한 방법이다. 다만 자동 검색은
불가능해(유튜브 검색 API도 키가 필요) 수동 큐레이션으로 커버리지를
좁히기로 사용자와 합의했다.

## Reconsider when

- Windy나 도시별 공식 API 키를 발급받기로 방향이 바뀌는 시점.
- 큐레이션 목록이 여행 등록 도시 대비 너무 좁아, 실사용에서 커버리지
  확장이 필요하다고 판단되는 시점.

## Still-rejected alternatives

- Windy Webcams API — 인증·비용 부담으로 보류; 키 발급을 결정하면 재검토.
- Windy embed 위젯 — 상업적 사용 금지 약관으로 제외.
- 도시별 공식 교통 카메라 API — 도시 한정성과 계약 부담으로 제외; 특정
  도시 커버리지가 꼭 필요해지면 그 도시만 개별 재검토.

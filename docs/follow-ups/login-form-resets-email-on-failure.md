# 로그인/회원가입 실패 시 이메일 필드가 초기화됨

## 증상

`app/login-form.tsx`에서 로그인이나 회원가입이 실패하면(예: 잘못된
비밀번호), 오류 문구는 정상적으로 뜨지만 이메일 입력 필드가 빈 값으로
초기화된다. 비밀번호 필드만 다시 채워서 제출하면 이메일이 비어 있는
채로 제출된다.

## 관찰한 증거

브라우저에서 실제로 재현했다: 이메일·비밀번호를 입력해 로그인 실패 →
비밀번호만 올바른 값으로 다시 입력해 제출 → 이메일 필드가 비어 있어
다시 로그인에 실패함. `document.getElementById('email').value`가 빈
문자열로 확인됨.

## 추정 원인

React 19의 form actions는 액션이 완료되면(성공·실패 무관) uncontrolled
폼을 네이티브 폼처럼 리셋하는 것으로 알려져 있다. 이 폼의 입력 필드가
React state로 제어되지 않고 `defaultValue` 없이 `name`만 있는
uncontrolled 필드라 리셋 대상이 된다.

## 시도한 것

이번 스펙(`docs/specs/auth-signup-login/`)의 관찰 가능한 인수 기준(오류
문구 표시)은 만족하므로 범위 안에서 고치지 않고 넘어갔다. 별도 수정은
시도하지 않았다.

## 제안하는 다음 단계

- `action`의 반환 state에 제출했던 이메일 값을 포함시켜, 실패 시 해당
  값을 `defaultValue`로 되돌려주는 방식으로 고칠 수 있다.
- 또는 이메일 필드를 `useState`로 제어값으로 바꿔 액션 실행과 무관하게
  유지되게 할 수 있다.
